## ✅ 验证的正常流程

```
① 首页 index
    ↓
② 点「免费排盘」→ 输入页 input
    ↓
③ 填性别/日期/时辰 → 点「开始排盘」
    ↓
④ L0 结果页 result（四柱 + 五行 + 命格预判带锁）
    ↓
⑤ 点升级入口（比如「¥9.9 财格速查」）
    ↓
⑥ 支付页 payment（含订单卡 + 权益列表）
    ↓
⑦ 点「微信支付」→ 模拟 1.2 秒后跳转
    ↓
⑧ 支付成功页 pay-success（印章 + 订单号）
    ↓
⑨ 点「查看我的报告」→ 真正的 L2 内容
```

## 🔁 同步策略说明

| 部分 | H5 → 小程序 |
|------|-----------|
| `bazi.js` 算法 | **100% 同文件**（已用双环境导出，两边直接共用）|
| 页面结构 | HTML 模板 → WXML（字符串 → 标签）|
| 样式 | CSS `px` → WXSS `rpx`（数值 × 2） |
| 事件 | `onclick` → `bindtap` |
| 支付 | 模拟 → `wx.requestPayment` |

模式确认后，军师可以 1-2 小时内完成从 H5 到小程序的回迁。
