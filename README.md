# 招财簿 · ZhaocaiBu

> **程序员 × 命理师 × A股玩家** — 三栖 IP · 全网稀缺卡位

「招财簿」是一个面向 **25-45 岁技术从业者** 的财运 SaaS 产品，用八字命理 + 市场数据结合的方式，提供每日财运签、大师团分析和板块详批。

## 🚀 本地开发

### H5 端

```bash
cd caiyunju-h5

# 启动开发服务器（端口 5817）
node server.js

# 访问 http://localhost:5817
```

### 小程序端

```bash
# 用微信开发者工具打开 caiyunju-miniapp/ 目录
# AppID：开发阶段可用 touristappid
# 正式版需替换为已备案的真实 AppID
```

### 后端数据服务

```bash
cd server-marketSign

# 安装依赖
pip install flask

# 生成每日签文数据
python3 generate_daily_sign.py

# 启动 API 服务（端口 5818）
python3 serve_flask.py
```

## 📡 API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/sign` | GET | 获取今日签文数据（含签级/趋势/大师团） |
| `/api/masters` | GET | 8位大师独立分析结果 |
| `/api/index` | GET | 沪指实时行情（通过代理抓取） |
| `/api/market-snapshot` | GET | 市场快照（板块涨跌/资金流/情绪） |
| `/health` | GET | 健康检查（data_age / uptime） |
